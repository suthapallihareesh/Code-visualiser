Questions

Do I need to install Java, GCC or Python myself?

Windows: no, all of them are included. macOS and Linux: Java and Python are included. For C and C++ you need the compiler that comes with your system: on macOS run xcode-select --install once, on Linux install build-essential (or your distribution's equivalent). Code Studio tells you if it is missing.

Does it need internet?

Only to download it. Compiling and running happen on your computer with no connection.

Why can't I just use it in the browser?

A web page cannot start real compilers on your computer. That is why Code Studio is an app you install, so the results come from the genuine tools.

Windows says "Windows protected your PC".

This warning appears for apps from small publishers. Choose More info, then Run anyway, if you downloaded the installer from this project's official release page.

macOS says the app is damaged or from an unidentified developer.

The app is not signed with an Apple developer certificate yet. Open the Applications folder, right-click Code Studio, choose Open, then confirm. If macOS still refuses, run xattr -dr com.apple.quarantine /Applications/"Code Studio.app" in Terminal.

Is my code uploaded anywhere?

No. Your code stays on your computer.
